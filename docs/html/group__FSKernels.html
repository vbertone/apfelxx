Detailed Description

NLO (O(alpha_s)) kernels K_{ij}(x) for transitions between factorisation schemes, following arXiv:2501.18289, eqs. (69)-(72).

Each kernel is decomposed as K(x) = [a0/(1-x)]_+ + [a1*ln(1-x)/(1-x)]_+ + b*ln(1-x)

  • c*ln(x) + P + Delta*delta(1-x)

mapped to apfel::Expression methods as: Regular(x) = b(x)*ln(1-x) + c(x)*ln(x) + P(x) Singular(x) = (a0 + a1*ln(1-x)) / (1-x) Local(x) = Delta + a0*ln(1-x) + (a1/2)*ln^2(1-x)

Channels are indexed as: 1=qq, 2=qg, 3=gq, 4=gg. Classes that vanish identically use apfel::Null.
