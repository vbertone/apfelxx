Detailed Description

template<class T>
class apfel::Set< T >

The Set template class allocates a collection of objects of type T along the ConvolutionMap and provides the methods to perform operations between different types of objects T.

Examples
dglap_test.cc, dglap_test_phys.cc, dglapqcdqed_test.cc, gpd_test.cc, set_test.cc, sum_rules_test.cc, sum_rules_test_phys.cc, sum_rules_test_qcdqed.cc, and tmd_test.cc.
